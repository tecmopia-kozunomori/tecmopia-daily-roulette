# テクマくん 毎日ルーレット

テクモピア公津の杜店向けの、LINE LIFF + GitHub Pages + Google Apps Script 構成の「1日1回・ハズレなし」ルーレットです。

## 初期仕様

- 1日1回だけ挑戦可能（日本時間の日付で判定）
- 3種類のどれかが必ず当選
  - メダル10枚：50
  - クレーンゲーム 1PLAY無料：20
  - クレーンゲーム 1PLAY増量：30
- 当選特典は当日23:59まで
- スタッフ確認後に「使用済み」処理
- 翌日になると再び挑戦可能
- 抽選結果はGAS側で決定するため、フロント側を書き換えても景品を自由に選べない設計
- LINEユーザーIDそのものはスプレッドシートへ保存せず、GAS側でSHA-256化した識別子を保存

## まずブラウザで見た目を確認

`js/config.js` が初期状態のままなら、自動でデモモードになります。

GitHub Pagesへアップする前でも、ローカルHTTPサーバーで開けばルーレット演出を確認できます。

デモモードではブラウザの localStorage を使って「本日1回」を再現します。本番の1日1回判定には使いません。
